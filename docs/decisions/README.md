# Architectural Decision Records

Accepted decisions for pseudonymize-text, in [MADR](https://adr.github.io/madr/)
format. Files are named `ADR_###.md` and cited by number across source, tests,
and the changelog — see [ADR_001](ADR_001.md) for why this project keeps the
`ADR_###` filename rather than the canonical MADR `NNNN-title` form.

| ADR | Decision | Status | Date |
|---|---|---|---|
| [ADR_001](ADR_001.md) | Adopt MADR for architectural decisions | accepted | 2026-05-25 |
| [ADR_002](ADR_002.md) | Mail-part handling: pseudonymize text/*, drop non-text parts | accepted | 2026-05-25 |
| [ADR_003](ADR_003.md) | Jurisdiction scope: GDPR-primary, jurisdiction-tagged detectors | accepted | 2026-06-22 |

To add an ADR: copy the structure of [ADR_002](ADR_002.md) or
[ADR_003](ADR_003.md), increment the number, and add a row above.
